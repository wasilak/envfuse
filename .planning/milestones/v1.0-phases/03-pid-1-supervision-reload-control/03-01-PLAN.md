| supervisor -> child process API | Privileged kill/terminate actions can cause availability impact |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Denial of Service | `internal/supervisor/supervisor.go` stop path | mitigate | Enforce bounded `shutdown_timeout` (D-01/D-02) with child-only SIGKILL escalation (D-03). |
| T-03-02 | Tampering | signal forwarding path | mitigate | Accept only SIGINT/SIGTERM handling via `signal.NotifyContext`; ignore arbitrary custom signal routing. |
| T-03-03 | Repudiation | supervision outcomes | mitigate | Emit typed reasons (`child_exited`, `startup_failed`, `forced_kill`) per D-16 and assert in tests. |
| T-03-04 | Elevation of Privilege | process-kill scope | mitigate | Kill child process only, not full process group, to avoid collateral process termination (D-03). |
</threat_model>
