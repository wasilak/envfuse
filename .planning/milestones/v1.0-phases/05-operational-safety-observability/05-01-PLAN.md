## Objective

Initialize `slog` with a JSON handler writing to stderr in `main.go`, controlled by `ENVFUSE_LOG_LEVEL`. Replace all `fmt.Print*` calls in `main.go` with structured `slog.*` calls. Emit the D-08 INFO startup summary after the first successful sync cycle. Emit D-13 DEBUG event (env var names applied) and D-14 DEBUG event (template render details) from the data already present in `CycleResult`.

This plan establishes the logging foundation that Wave 2 (supervisor events) depends on.

## Tasks

### 1. Initialize slog in main.go and replace fmt.Print* calls

**File:** `cmd/envfuse/main.go`

**Changes:**

1. Add imports: `"log/slog"`, `"os"` (already imported), `"strings"`.

2. At the top of `main()`, before `flag.Parse()`, add a `initLogger()` call (or inline the initialization):

   ```
   func initLogger() {
       levelVar := new(slog.LevelVar) // default INFO
       if raw := os.Getenv("ENVFUSE_LOG_LEVEL"); raw != "" {
           switch strings.ToUpper(raw) {
           case "DEBUG":
               levelVar.Set(slog.LevelDebug)
           case "WARN":
               levelVar.Set(slog.LevelWarn)
           case "ERROR":
               levelVar.Set(slog.LevelError)
           // INFO is the default; any unrecognized value stays at INFO
           }
       }
       slog.SetDefault(slog.New(slog.NewJSONHandler(os.Stderr, &slog.HandlerOptions{Level: levelVar})))
   }
   ```

   Call `initLogger()` as the very first statement in `main()`, before `flag.Parse()`.

3. Replace `fmt.Println(string(result.Status))` (line 28) with a structured slog call. After the first `RunSingleCycleWithStoreFromConfig` call:
   - On success path: emit the D-08 startup summary (see Task 2 below).
   - On failure path (non-success status): emit `slog.Error("initial sync failed", "status", string(result.Status), "error_class", result.ErrorClass)` then `os.Exit(1)`.

4. Replace `fmt.Fprintln(os.Stderr, err)` in the `-once` branch (after `runDirect` fails) with `slog.Error("child exec failed", "err", err)`.

5. Replace `fmt.Fprintln(os.Stderr, err)` calls for config-load and parse errors (lines 53, 57, 61, 65 area) with `slog.Error` calls:
   - `config.LoadConfig` error: `slog.Error("load config failed", "err", err)`
   - `cfg.ParsedShutdownTimeout()` error: `slog.Error("invalid shutdown_timeout", "err", err)`
   - `cfg.ParsedReloadPollInterval()` error: `slog.Error("invalid reload_poll_interval", "err", err)`
   - `cfg.ParsedReloadCooldown()` error: `slog.Error("invalid reload_cooldown", "err", err)`

6. Remove the `"fmt"` import if no `fmt.*` calls remain in main.go after replacements. Check `mergeEnvForChild` — it still uses `fmt.Sprintf`, so `"fmt"` stays.

### 2. Emit D-08 INFO startup summary and DEBUG detail events

**File:** `cmd/envfuse/main.go`

After `RunSingleCycleWithStoreFromConfig` returns a success result, and before entering the supervisor or exec branch, emit:

**D-08 INFO startup summary:**
```
slog.Info("envfuse started",
    "provider_type", cfg_provider_type,   // read from loaded config or result
    "paths_fetched", len(result.FetchedPaths),
    "env_vars_applied", len(result.AppliedEnv),
    "files_rendered", len(result.RenderedFiles),
    "fingerprint", result.Fingerprint[:8],
)
```

Note: `provider_type` is in the config file. At the point after the first cycle, the config has already been loaded inside `RunSingleCycleWithStoreFromConfig`. To expose it for the startup log, load the config explicitly before the first cycle call (reuse the returned config rather than reloading it). Refactor `main()` to call `config.LoadConfig(configPath)` first, handle error, then construct the provider and coordinator inline — OR load config separately just to read `provider_type` for the log line. The simpler approach: load config once at the top, build provider from it, run the cycle, then log. This also allows passing config fields to the supervisor without a second load call later. If this refactor is done, remove the duplicate `config.LoadConfig` call later in main.

Fingerprint truncation: use `result.Fingerprint[:8]` only if `len(result.Fingerprint) >= 8`, otherwise use the full fingerprint. Guard with a helper or inline `if len(...) >= 8`.

**D-13 DEBUG env var names applied:**
```
slog.Debug("env vars applied", "names", result.AppliedEnv)
```
`result.AppliedEnv` is `[]string` of env var names only (never values — confirmed by coordinator.go line 138-141 which only appends the key, not value).

**D-14 DEBUG template render details:**
```
slog.Debug("templates rendered", "output_paths", result.RenderedFiles)
```
`result.RenderedFiles` is `[]string` of output file paths, set in coordinator.go lines 154-158.

Both DEBUG events fire after the D-08 INFO line.
