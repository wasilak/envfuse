<decisions>
- vault_address is optional at config level; if unset, VAULT_ADDR env var is used (api.DefaultConfig reads it). Config validation rejects addresses that start with http:// when vault_address is explicitly set.
- vault_token is optional; VAULT_TOKEN env var is the standard operator interface. config field overrides it.
- vault_mount defaults to "secret" (standard KVv2 mount) if omitted.
- vault_tls_ca_cert is optional; when empty, system CA pool is used (standard Go tls behavior).
- Provider factory becomes buildProvider(ctx, cfg) in coordinator.go, used by both RunSingleCycle* functions.
- ErrorClass "provider_init_failed" is returned when buildProvider returns an error.
- resourceURI passed to Fetch is used as the path argument to KVv2.Get — it must NOT include the mount prefix.
</decisions>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator config → Vault address | Operator-supplied address must be validated before use in TLS context |
| envfuse process → Vault server | Remote HTTPS calls carry Vault tokens — network interception is the primary threat |
| Vault token → envfuse config | Token in config file is sensitive; not logged, not surfaced in cycle results |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | Vault token in config | mitigate | Token never logged or included in CycleResult. Config loaded from file; file permissions are operator responsibility. |
| T-04-02 | Tampering | TLS certificate validation | mitigate | `api.TLSConfig.Insecure` is never set to true. http:// vault_address rejected at LoadConfig (SECU-02). |
| T-04-03 | Spoofing | Vault server identity | mitigate | TLS with system CAs (or explicit CA) validates server certificate. No InsecureSkipVerify path exists in production code. |
| T-04-04 | Denial of Service | per-path fetch timeout | accept | Existing coordinator per-path timeout (2s) applies to vault Fetch calls — no additional mitigation needed. |
| T-04-05 | Information Disclosure | secret data in error messages | mitigate | Error messages include path name and error type but never secret values. |
</threat_model>
