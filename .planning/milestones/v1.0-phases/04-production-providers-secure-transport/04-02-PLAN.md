<decisions>
- aws_region is optional at config level; if unset, AWS_REGION env var or SDK default is used.
- aws_endpoint is optional; only used for LocalStack or other test endpoint overrides. Never set in production.
- secretsManagerAPI is a narrow interface (single-method) defined in the aws provider package for testability.
- NewWithClient(client secretsManagerAPI) constructor is exported for test injection; New(ctx, cfg) is the production path.
- Binary secrets (SecretBinary non-nil, SecretString nil) return a clear "binary secrets not supported" error.
- Non-JSON SecretString returns a decode error with the path name — operator must store secrets as JSON maps.
- SECU-02 for AWS is satisfied by SDK v2 design; no additional TLS configuration is needed or added.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| envfuse process → AWS Secrets Manager API | Remote HTTPS calls use AWS credential chain — IAM role or env var credentials are the trust anchor |
| SecretString content → decoded map | Operator-stored JSON in AWS is trusted; malformed JSON produces a decode error, not a crash |
| aws_endpoint config → SDK endpoint | Endpoint override is intended for test environments; production configs must not set it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Information Disclosure | AWS credentials in process | accept | Credentials managed by IAM role or env vars (standard ECS/Kubernetes pattern). Not logged by envfuse. |
| T-04-07 | Tampering | SecretString JSON content | mitigate | JSON decode errors surface immediately; malformed secrets abort the cycle (SYNC-03 semantics). |
| T-04-08 | Denial of Service | aws_endpoint HTTP override | mitigate | aws_endpoint is documented as test-only. Production config should not set it. Not validated in code — operator responsibility. |
| T-04-09 | Information Disclosure | secret values in decode errors | mitigate | Decode error includes path name and error type but never the raw SecretString content. |
| T-04-10 | Denial of Service | IMDSv2 metadata timeout | mitigate | Caller's context is passed to awsprovider.New — cancellation propagates to LoadDefaultConfig and IMDS calls. |
</threat_model>
