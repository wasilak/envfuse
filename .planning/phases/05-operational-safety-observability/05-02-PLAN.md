## Objective

Then write redaction tests covering all three high-risk paths (provider fetch errors, template rendering errors, config validation errors) that assert known secret values do not appear anywhere in captured log output (D-07, SECU-01).

#### D-09: Cycle outcome event (every poll tick)

In `watch()`, inside the `case <-ticker.C:` branch, after `RunSingleCycleWithStoreFromConfig` returns, emit a cycle outcome event. Capture latency around the call:

```
cycleStart := time.Now()
cycleResult := synccycle.RunSingleCycleWithStoreFromConfig(shutdownCtx, cfg.ConfigPath, cfg.Store)
latencyMs := time.Since(cycleStart).Milliseconds()

attrs := []any{
    "status", string(cycleResult.Status),
    "latency_ms", latencyMs,
}
if cycleResult.Status != synccycle.CycleStatusSuccess {
    attrs = append(attrs, "error_class", cycleResult.ErrorClass)
}
slog.Info("sync cycle", attrs...)
```

This emits on every tick: success cycles log `status=success` and `latency_ms`; failed/aborted cycles also log `error_class`. `ErrorClass` is a code string (e.g., `"fetch_failed"`, `"config_invalid"`) — never a secret value.

#### D-10: Fingerprint change + restart event

In `watch()`, at the point where effective config has changed and a restart is about to be triggered (both the immediate restart path and the pending/cooldown path), emit before sending SIGTERM:

For immediate restart (line ~162, after `ct.inCooldown()` check is false):
```

    "fingerprint_old", truncate8(*lastFingerprint),  // value before update
    "fingerprint_new", truncate8(cycleResult.Fingerprint),
    "restart_reason", string(supervisor.ReasonConfigChanged),
)
```

Note: `*lastFingerprint` is updated to `cycleResult.Fingerprint` just before this point — capture old value first. Restructure the assignment sequence: save old fingerprint, update `*lastFingerprint`, then emit the log line with both.

For the coalesced pending restart path (when `ct.drainPending()` fires at start of tick):

    "restart_reason", string(ReasonConfigChanged),

The old/new fingerprints are not available at drain time (the change was recorded in a previous tick), so emit only `restart_reason` for the deferred case.

### 2. Write redaction tests for SECU-01

**File:** `internal/sync/redaction_test.go` (new file)

Write three table-driven test functions that capture slog output to a `bytes.Buffer` and assert that a known fake secret value does not appear anywhere in the buffer.

**Test setup pattern:**

```go
func captureLog(t *testing.T) (*bytes.Buffer, func()) {
    t.Helper()
    buf := &bytes.Buffer{}
    handler := slog.NewJSONHandler(buf, &slog.HandlerOptions{Level: slog.LevelDebug})
    orig := slog.Default()
    slog.SetDefault(slog.New(handler))
    return buf, func() { slog.SetDefault(orig) }
}
```

**Test 1: Provider fetch error does not leak secret value**

```go
func TestRedaction_ProviderFetchError(t *testing.T) {
    // Arrange: a provider that returns an error message containing a fake secret
    const fakeSecret = "s.fake-vault-token-abc123"
    // The provider error includes the secret in its message to simulate a badly
    // formatted upstream error (e.g., Vault returning token in error body).
    p := &errorProvider{err: fmt.Errorf("request failed with token %s", fakeSecret)}
    store := state.NewStore()
    c := NewCoordinatorWithStore(p, store, 100*time.Millisecond)

    buf, restore := captureLog(t)
    defer restore()

    result := c.RunCycle(context.Background(), []string{"secret/app"})

    assert that result.Status != CycleStatusSuccess
    assert that strings.Contains(buf.String(), fakeSecret) == false,
        "log output must not contain fake secret value"
}
```

Note: The coordinator returns `ErrorClass` codes ("fetch_failed", "fetch_aborted"), not raw error messages. This test verifies that even when the upstream error contains a secret, the log output (which only logs ErrorClass) does not expose it. This test primarily documents and locks the passive-redaction contract.

**Test 2: Template rendering error does not leak secret value**

```go
func TestRedaction_TemplateRenderError(t *testing.T) {
    const fakeSecret = "s.fake-template-secret-xyz789"
    // Use a local provider that returns a value containing the fake secret.
    // The template renders it into content — if the render error path logged
    // template content, the secret would appear.
    p := &staticProvider{data: map[string]map[string]any{
        "secret/app": {"password": fakeSecret},
    }}
    store := state.NewStore()
    c := NewCoordinatorWithStore(p, store, 100*time.Millisecond)

    // Template that will cause a render error: references an undefined key
    templates := []config.TemplateSpec{{
        Source:       "{{ .undefined_key }}",
        TargetPath:   t.TempDir() + "/out.txt",
        RequiredPaths: []string{"secret/app"},
    }}

    buf, restore := captureLog(t)
    defer restore()

    result := c.RunCycleWithVectors(context.Background(), []string{"secret/app"}, nil, templates)

    assert that result.Status != CycleStatusSuccess
    assert that strings.Contains(buf.String(), fakeSecret) == false,
        "log output must not contain fake secret value"
}
```

**Test 3: Config validation error does not leak secret value**

Use a structurally invalid config to force a `config_invalid` error before any network call. The trick: embed the fake secret as the `vault_token` value AND also include an invalid field (`"unknown_field": "..."`) which triggers `DisallowUnknownFields` in `config.LoadConfig`, producing a validation error. This ensures the error is `config_invalid` and never reaches the provider.

```go
func TestRedaction_ConfigValidationError(t *testing.T) {
    const fakeSecret = "s.fake-config-token-def456"
    // Config has an unknown field to trigger DisallowUnknownFields decode error.
    // The vault_token contains the fake secret to verify it never appears in logs.
    cfgContent := fmt.Sprintf(`{
        "provider_type": "vault",
        "vault_address": "https://vault.example.com",
        "vault_token": %q,
        "vault_mount": "secret",
        "secret_paths": ["secret/app"],
        "unknown_field_triggers_invalid": true
    }`, fakeSecret)
    dir := t.TempDir()
    cfgPath := filepath.Join(dir, "seon.json")
    os.WriteFile(cfgPath, []byte(cfgContent), 0600)

    buf, restore := captureLog(t)
    defer restore()

    result := RunSingleCycleWithStoreFromConfig(context.Background(), cfgPath, state.NewStore())

    assert that result.Status != CycleStatusSuccess
    assert that result.ErrorClass == "config_invalid" (or non-empty, confirming config error path)
    assert that strings.Contains(buf.String(), fakeSecret) == false,
        "log output must not contain vault token value even on config validation error"
}
```

**Test infrastructure types** (add in the test file or a `_test` helper file):

```go
// errorProvider always returns err from Fetch.
type errorProvider struct{ err error }
func (p *errorProvider) Fetch(_ context.Context, _ string) (map[string]any, error) {
    return nil, p.err
}

// staticProvider returns a fixed dataset.
type staticProvider struct{ data map[string]map[string]any }
func (p *staticProvider) Fetch(_ context.Context, path string) (map[string]any, error) {
    if d, ok := p.data[path]; ok {
        return d, nil
    }
    return nil, fmt.Errorf("path not found: %s", path)
}
```

The redaction tests do not emit any slog calls themselves (they only capture). The absence of the secret in the buffer is the assertion. Use `strings.Contains(buf.String(), fakeSecret)` and fail with `t.Errorf` if it returns true.
